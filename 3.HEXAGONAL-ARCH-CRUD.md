# CRUD SENCILLO CON ARQUITECTURA HEXAGONAL

Para esto primero refactorizamos lo que habiamos generado con:

```bash
nest g res modules/nameModule
```

## Orden

1. Creamos las carpetas **domain**, **application** e **infrastructure**

1. **Domain**: Movemos la carpeta **entities** a **domain** y creamos
   una carpeta llamada **repositories**

1. **Application**: Creamos una carpeta **use-cases** y eliminamos
   **users.service.ts**

1. **Infrastructure**: creamos la carpeta **persistence** y acá
   es donde usaremos prisma-orm. Además crearemos otra carpeta **web**
   y a esta moveremos **users.controller.ts**

Ahora, fuimos en el siguiente orden en los ficheros:

### Recuperar todos los registros

1. Domain

   - user.repository.port.ts
1. Application
   - find-users.use-case.ts
1. Infrastructure
   - user-prisma.repository.adapter.ts
   - users.controller.ts
1. Module
   - users.module.ts // Agregamos el caso de uso
