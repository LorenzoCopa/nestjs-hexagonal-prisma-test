# NestJS CRUD HEXAGONAL ARCHITECTURE

> [!**NOTE**]
> Instalar todos los paquetes.

Creamos las carpetas vacías

- modules/
- shared/ && shared/infrastructure/

Ya después generamos los siguientes módulos

## Config

```bash
# generamos el módulo config para variables de entorno
nest g mo config/app-config --flat
```

## Shared

### Common

```bash
# generamos el módulo common en la carpeta shared
nest g mo shared/infrastructure/common
```

### Prisma

```bash
# generamos el módulo de prisma
nest g mo shared/infrastructure/database/prisma
```

```bash
# generamos el service de prisma
nest g s shared/infrastructure/database/prisma
```

## Modules

```bash
# generamos el módulo users dentro de modules
# Refactorizamos en HEXAGONAL
nest g res modules/users
```

## Config Module

Ya generados estos módulos, comenzamos por configurar los ficheros de
config para las variables de entorno.

- app.config.ts
- app.constants.ts
- app-config.module.ts

## Common Module

- pipes/validation.pipe.ts
- common.module.ts

## Prisma ORM

Las dependencias de prisma 7 deben estar instalados

```bash
# Vemos todos los comandos que tiene prisma
npx prisma
```

```bash
# Iniciamos Prisma
npx prisma init
```

- Formateamos prisma.config.ts
- Configuramos schema.prisma **output** y **moduleFormat**

```prisma
generator client {
  provider     = "prisma-client"
  output       = "../src/shared/infrastructure/database/prisma/generated/prisma"
  moduleFormat = "cjs"
}
```

Siempre que editemos el archivo **schema.prisma** debemos ejecutar el comando:

```bash
# generamos el prisma client
npx prisma generate
```

Configuramos los archivos:

- prisma.service.ts
- prisma.module.ts

Cuando definimos una o más tablas después de ello realizamos la migración
y generamos el cliente prisma.

```bash
# Migramos las tablas a la base de datos
npx prisma migrate dev
```
