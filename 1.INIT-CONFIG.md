# Configuraciones Iniciales

**tsconfig.json**, en este archivo agregamos al final del paths

```json
{
  "compilerOptions": {
    ...
    "paths": {
      "@/*": ["src/*"],
      "@config/*": ["src/config/*"],
      "@modules/*": ["src/modules/*"],
      "@shared/*": ["src/shared/*"],
      "@common/*": ["src/shared/infrastructure/common/*"],
      "@database/*": ["src/shared/infrastructure/database/*"]
    }
  }
}
```

**tsconfig.build.json**, lo mismo

```json
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "paths": {
      "@/*": ["src/*"],
      "@config/*": ["src/config/*"],
      "@modules/*": ["src/modules/*"],
      "@shared/*": ["src/shared/*"],
      "@common/*": ["src/shared/infrastructure/common/*"],
      "@database/*": ["src/shared/infrastructure/database/*"]
    }
  },
  "exclude": ["node_modules", "test", "dist", "**/*spec.ts"]
}
```

> [!NOTE]
> Esto se puede agregar cuando tengamos la estructura definida
> de nuestra app, ya que si lo no sabemos que paths pueden crecer,
> entonces será código y comandos inncesarios en nuestros tsconfig.json
> y tsconfig.build.ts ya que en este podria ir también infrastructure,
> y otros que se usen y estén en la raíz.
